# 面向智能电网的电力用户隐私保护与数据安全聚合系统 - 开发文档

## 1. 项目概述

### 1.1 项目目标
实现一套“智能电表—雾节点—控制中心”三层架构的隐私保护数据聚合系统，满足以下核心功能：
- 登录与身份管理界面（管理员认证）
- 电力数据模拟/导入与终端处理界面
- 数据编码、同态加密、数字签名等密码处理模块
- 加密数据上报、雾端聚合与中心解密展示模块
- 聚合结果完整性验证（双层签名）
- 重放检测与日志审计模块

### 1.2 系统核心指标
- 隐私保护：雾节点无法解密个体用户数据，控制中心仅获取聚合统计结果
- 完整性：任何篡改行为被签名验证机制检测并拒绝
- 抗重放：基于序列号+时间戳的组合检测
- 性能：100用户并发，雾节点聚合耗时≤500ms，中心验签解密≤300ms
- 通信压缩：多维数据打包后加密，报文大小减少约50%

## 4. 数据库设计

### 4.1 E-R 关系
- **device** (1) ←→ (N) **report_log**
- **device** (1) ←→ (N) **aggregation**（通过participant_list JSON间接）
- **audit_log** 独立，不直接关联

### 4.2 表结构

#### 4.2.1 device（设备表）
```sql
CREATE TABLE device (
    device_id VARCHAR(32) PRIMARY KEY,
    public_key TEXT NOT NULL,
    status VARCHAR(16) DEFAULT 'active',
    last_report_time DATETIME,
    last_seq INT DEFAULT 0,
    register_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_status (status)
);
```

#### 4.2.2 report_log（上报日志表）
```sql
CREATE TABLE report_log (
    log_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    device_id VARCHAR(32) NOT NULL,
    timestamp DATETIME(3) NOT NULL,
    seq INT NOT NULL,
    ciphertext TEXT NOT NULL,
    ciphertext_sq TEXT NOT NULL,
    signature VARCHAR(128) NOT NULL,
    verify_result BOOLEAN NOT NULL,
    reject_reason VARCHAR(256),
    INDEX idx_device_time (device_id, timestamp),
    FOREIGN KEY (device_id) REFERENCES device(device_id)
);
```

#### 4.2.3 aggregation（聚合结果表）
```sql
CREATE TABLE aggregation (
    agg_id BIGINT AUTO_INCREMENT PRIMARY KEY,
    window_start DATETIME(3) NOT NULL,
    window_end DATETIME(3) NOT NULL,

    sum_voltage DECIMAL(10,2) NOT NULL,

    verify_result BOOLEAN NOT NULL,

);
```

```sql
CREATE TABLE audit_log (
    audit_id BIGINT AUTO_INCREMENT PRIMARY KEY,
```

## 5. 核心功能模块实现说明

### 5.1 登录与身份管理
- **前端**：登录表单，用户名/密码，提交至 `/api/auth/login`。
- **后端**：使用Spring Security + JWT，验证成功后返回token，后续请求携带在Header中。
- **会话管理**：token有效期24小时，支持登出（黑名单）。
- **默认管理员**：admin / admin123（可配置）。

### 5.2 电力数据模拟/导入与终端处理界面
- **数据模拟**：支持正态分布或均匀分布随机生成5维数据（电压、电流、有功、无功、功率因数）。
- **CSV导入**：格式为 `timestamp,voltage,current,active_power,reactive_power,power_factor`，每行一个采样点。
- **终端处理界面**：前端展示所有模拟终端的ID、状态（运行/停止）、最后上报时间，可启动/停止单个终端，或批量启动。
- **后端接口**：`POST /api/simulator/start`、`POST /api/simulator/stop`、`GET /api/simulator/status`。

### 5.3 密码处理模块（编码、加密、签名）
- **数据编码**：`DataPacker`类实现超递增序列的生成、打包、解码。维度k=5，最大值根据实际数据范围设定（如电压250V，电流2000，功率5000等）。需处理溢出：预计算`P_max`，若大于Paillier模数n则归一化。
- **同态加密**：`PaillierCrypto`类提供密钥生成、加密、解密、同态加法。优化：固定g=n+1，预计算随机数幂表，解密支持CRT。
- **数字签名**：`SchnorrSigner`类基于BouncyCastle实现EC-Schnorr（secp256k1）。签名消息格式统一为竖线分隔的字符串。

### 5.4 加密数据上报
- 终端使用`RestTemplate`每60秒（可配置）向雾节点`/api/report`发送POST请求，请求体包含设备ID、时间戳、序列号、密文（Base64）、平方密文（Base64）、签名（十六进制）。
- 支持并发上报：每个终端独立线程，启动时随机延迟0-30秒避免同时拥塞。

### 5.5 雾端聚合与中心解密展示
- **雾端聚合**：
  - 使用`AtomicReference<BigInteger>`无锁累加总密文和平方密文。
  - 使用`ConcurrentHashMap`记录参与设备。
  - 每5分钟（可配置）触发聚合：生成聚合密文，雾节点对`(窗口起止, 设备列表, 聚合密文, 平方聚合密文)`进行签名，转发至控制中心`/api/center/aggregate`。
- **中心解密展示**：
  - 验证雾签名后，调用Paillier解密得到总和打包值和平方总和打包值。
  - 解码得到各维度总和与平方和，计算均值和方差。
  - 存入`aggregation`表。
  - 前端通过`GET /api/center/statistics`获取数据，使用ECharts绘制折线图（功率、电压、电流趋势）。

### 5.6 聚合结果完整性验证
- **终端签名验证**：雾节点收到上报后，使用设备公钥验证签名，失败则拒绝并记录审计日志。
- **雾端签名验证**：控制中心收到聚合结果后，使用雾节点公钥验证签名，失败则丢弃并告警。
- 前端展示区显示每次查询的签名验证状态（通过/失败）。

### 5.7 重放检测与日志审计
- **重放检测**：
  - 雾节点维护`ConcurrentHashMap<String, Integer> lastSeqMap`存储每个设备最新的序列号。
  - 若上报的`seq ≤ lastSeq`，则拒绝并记录`REPLAY_ATTACK`事件。
  - 同时检查时间戳：若`|timestamp - now| > 5分钟`，拒绝并记录`TIMESTAMP_OUT_OF_WINDOW`。
- **日志审计**：
  - 所有安全事件（签名失败、重放攻击、非法设备等）通过`AuditLogger`异步写入`audit_log`表。
  - 前端提供审计日志查看界面，支持按级别、模块、时间范围筛选，可导出CSV。

## 7. 核心算法伪代码

### 7.1 超递增序列编码（DataPacker）
```java
// 生成序列
BigInteger[] generateSequence(int[] maxVals) {
    int k = maxVals.length;
    BigInteger[] a = new BigInteger[k];
    a[0] = BigInteger.ONE;
    for (int i = 1; i < k; i++) {
        BigInteger sum = BigInteger.ZERO;
        for (int j = 0; j < i; j++) {
            sum = sum.add(a[j].multiply(BigInteger.valueOf(maxVals[j])));
        }
        a[i] = sum.add(BigInteger.ONE);
    }
    return a;
}

// 打包
BigInteger pack(int[] data, BigInteger[] a) {
    BigInteger result = BigInteger.ZERO;
    for (int i = 0; i < data.length; i++) {
        result = result.add(a[i].multiply(BigInteger.valueOf(data[i])));
    }
    return result;
}

// 解码
int[] unpack(BigInteger packed, BigInteger[] a) {
    int[] data = new int[a.length];
    BigInteger remaining = packed;
    for (int i = a.length - 1; i >= 0; i--) {
        BigInteger[] div = remaining.divideAndRemainder(a[i]);
        data[i] = div[0].intValue();
        remaining = div[1];
    }
    return data;
}
```

### 7.2 Paillier加密（优化版）
```java
// 加密
BigInteger encrypt(BigInteger m, BigInteger n, BigInteger n2) {
    // 从预缓存中随机取一个 r^n mod n2
    BigInteger rn = precomputedRn[random.nextInt(precomputedRn.length)];
    BigInteger gm = BigInteger.ONE.add(m.multiply(n)).mod(n2);
    return gm.multiply(rn).mod(n2);
}

// 同态加法
BigInteger add(BigInteger c1, BigInteger c2, BigInteger n2) {
    return c1.multiply(c2).mod(n2);
}

// 解密
BigInteger decrypt(BigInteger c, BigInteger lambda, BigInteger mu, BigInteger n, BigInteger n2) {
    BigInteger u = c.modPow(lambda, n2);
    BigInteger L = u.subtract(BigInteger.ONE).divide(n);
    return L.multiply(mu).mod(n);
}
```

### 7.3 重放检测
```java
boolean checkReplay(String deviceId, int seq, long timestamp) {
    int lastSeq = lastSeqMap.getOrDefault(deviceId, 0);
    if (seq <= lastSeq) {
        auditLog(REPLAY_ATTACK, deviceId, "seq="+seq+" lastSeq="+lastSeq);
        return false;
    }
    long now = System.currentTimeMillis();
    if (Math.abs(timestamp - now) > ALLOWED_TIME_WINDOW_MS) {
        auditLog(TIMESTAMP_OUT_OF_WINDOW, deviceId, "diff="+(timestamp-now));
        return false;
    }
    lastSeqMap.put(deviceId, seq);
    return true;
}
```

## 12. 常见问题与解决方案

| 问题                           | 原因                    | 解决方法                                          |
| ------------------------------ | ----------------------- | ------------------------------------------------- |
| 前端登录后API返回401           | token未携带或过期       | 检查axios拦截器，刷新token                        |
| 密文解密后解码为负数           | 打包值超出n导致溢出     | 增大Paillier密钥长度或归一化数据                  |
| 雾节点聚合结果与控制中心不一致 | 并发累加时CAS失败未重试 | 使用`updateAndGet`确保原子性                      |
| 重放检测误判                   | 终端时间不同步          | 增大时间窗口或使用NTP同步                         |
| 数据库JSON字段查询慢           | 未建立索引              | 在`participant_list`上创建虚拟列索引（MySQL 8.0） |
